# Getting Started - Local Test Case Generator

**⏱️ Estimated Setup Time: 10-15 minutes**

## Step 1: Navigate to Project

```bash
cd C:\AI_QA_Engineering\02_Local_Testcase_generator\src
```

## Step 2: Install Dependencies

```bash
# Create virtual environment (recommended)
python -m venv venv
venv\Scripts\activate

# Install packages
pip install -r requirements.txt
```

**Expected output**: `Successfully installed streamlit requests pandas ...`

## Step 3: Configure Settings File

```bash
# Copy the template
copy .env.example .env
```

**Edit `C:\AI_QA_Engineering\02_Local_Testcase_generator\src\.env`:**

### Required: Jira Configuration

1. Go to https://id.atlassian.com/manage-profile/security/api-tokens
2. Click "Create API token"
3. Copy the token
4. Fill in:
   ```env
   JIRA_URL=https://your-domain.atlassian.net
   JIRA_EMAIL=your-email@example.com
   JIRA_API_TOKEN=paste-your-token-here
   ```

### Recommended: Ollama (Local LLM)

```env
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=gemma3:12b
OLLAMA_TIMEOUT=60
```

### Optional: Groq (Cloud Fallback)

1. Sign up at https://console.groq.com
2. Go to "API Keys" section
3. Create and copy your API key
4. Fill in:
   ```env
   GROQ_API_KEY=your-api-key-here
   GROQ_MODEL=llama-3.3-70b-versatile
   ```

## Step 4: Start Ollama Server

**Open a new terminal (keep it running):**

```bash
# Download Ollama from https://ollama.ai if not installed
ollama serve
```

**In another terminal, pull the model:**

```bash
ollama pull gemma3:12b
```

**Wait for download to complete** (~5GB for 12B model)

To use different models:
- `ollama pull llama2` - LLama 2
- `ollama pull mistral` - Mistral 7B  
- `ollama pull gemma3:27b` - Gemma 3 27B (requires more VRAM)

## Step 5: Run the Application

```bash
# From src/ directory with venv activated
streamlit run app.py
```

**Expected output**:
```
  You can now view your Streamlit app in your browser.

  Local URL: http://localhost:8501
```

**Automatically opens in browser** at `http://localhost:8501`

If not, manually open: http://localhost:8501

## Step 6: Configure in Settings Page

1. Click on "⚙️ Settings" in the sidebar
2. **Jira Tab**:
   - Your settings are pre-filled from `.env`
   - Click "🧪 Test Jira Connection"
   - Should show ✅ if credentials are correct
3. **Ollama Tab**:
   - Should show your model name
   - Click "🧪 Test Ollama Connection"
   - Should show ✅ if Ollama is running
4. **Groq Tab** (optional):
   - If you provided a key, click "🧪 Test Groq Connection"
   - Should show ✅ if key is valid

## Step 7: Generate Your First Test Cases

1. Click back to "🧪 Local Test Case Generator" (home)
2. In the chat box at the bottom, type:
   ```
   create test cases for VWO-49
   ```
   (Replace VWO-49 with a real issue key from your Jira)
3. Press Enter or click Send
4. Wait for:
   - ✅ "Fetching Jira issue..." (2-3 seconds)
   - ✅ "Generating test cases..." (5-30 seconds depending on Ollama speed)
5. See the table with test cases
6. **Download**:
   - Click "📥 Download CSV" to export as CSV
   - Click "📊 Download Excel" for formatted Excel file

## Step 8: Test Fallback (Optional)

To test what happens when Ollama is unavailable:

1. Stop Ollama server (Ctrl+C in the Ollama terminal)
2. In the app, type another Jira key
3. Should fall back to Groq and show: "Generated by: Groq"
4. Restart Ollama with `ollama serve` when done

## 🆘 Troubleshooting

### "Cannot connect to Ollama"
- **Check**: Is Ollama running in another terminal? (`ollama serve`)
- **Check**: Is model pulled? (`ollama pull gemma3:12b`)
- **Check**: Is port 11434 correct? (default is correct)
- **Fix**: Restart Ollama and the app

### "Jira Authentication Failed"
- **Check**: Is email correct?
- **Check**: Did you generate a new API token?
- **Check**: Is token correct (no spaces)?
- **Fix**: Regenerate token at https://id.atlassian.com/manage-profile/security/api-tokens

### "Jira Issue Not Found"
- **Check**: Is the issue key correct? (e.g., VWO-49, not vwo49)
- **Check**: Do you have access to the project?
- **Fix**: Verify issue exists in Jira, try a different issue

### "No valid Jira ID found"
- **Issue**: Your message doesn't include a Jira key
- **Fix**: Include the key in your message, e.g., "tc for VWO-49"

### App doesn't start
- **Error**: "ModuleNotFoundError: No module named 'streamlit'"
- **Fix**: Did you activate venv? Run `venv\Scripts\activate` again
- **Fix**: Did you run `pip install -r requirements.txt`?

### Excel file corrupted or won't open
- **Fix**: Try CSV export instead
- **Check**: Do you have Excel or LibreOffice installed?
